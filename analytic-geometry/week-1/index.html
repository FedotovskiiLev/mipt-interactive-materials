Переставлять множители можно только если это отдельно обосновано. Если AB = BA, матрицы называют перестановочными (коммутирующими).

03 · определитель

det A — одно число для квадратной матрицы

Для этой недели определитель нужен прежде всего как вход в правило Крамера: если det A ≠ 0, квадратная система имеет единственное решение.

det A = −2
Типичная ошибка: знак «минус» в 3×3 легко потерять. На странице используется разложение по первой строке: a·M₁₁ − b·M₁₂ + c·M₁₃.
04 · система Ax = b

Правило Крамера: заменяем столбец, не строку

В §6.4 Умнова правило сформулировано для квадратной системы: единственное решение существует тогда и только тогда, когда Δ = det A ≠ 0.

Сначала попробуй определить, какой столбец надо заменить для Δ₁.

Алгоритм, который стоит уметь восстановить без сайта
1Запиши матрицу коэффициентов A и столбец свободных членов b.
2Посчитай Δ = det A.
3Для Δᵢ замени i-й столбец A на b.
4Если Δ ≠ 0, xᵢ = Δᵢ / Δ.
5Подставь найденные значения обратно хотя бы в одно уравнение.
05 · домашка из проектного чата

Матрица, которая коммутирует с любой матрицей 2×2

Это тот тип задачи, который мы уже проходили в проектном чате. Здесь решение спрятано лестницей подсказок.

доказательство через элементы

Пусть

abcd
= X,
efgh
= B.

Найди все X, для которых XB = BX для любой вещественной матрицы B второго порядка.

Перемножь X·B и B·X. Равенство матриц означает равенство четырёх соответствующих элементов.
XB = [[ae+bg, af+bh], [ce+dg, cf+dh]],
BX = [[ea+fc, eb+fd], [ga+hc, gb+hd]].
Из (1,1): bg = fc для любых f и g. Можно независимо выбирать f и g. Это заставляет b = 0 и c = 0.
Сравни (1,2): af = fd для любого f. Значит a = d.
Получаем X = [[a,0],[0,a]] = aE. То есть со всеми матрицами второго порядка коммутируют ровно скалярные матрицы λE. Это совпадает с тем выводом, к которому ты пришёл в чате: b=c=0 и a=d.
Крамер · из чата

Главный навык

В проектном чате ты правильно восстановил схему: сначала Δ, затем Δ₁, Δ₂, … заменой столбца на свободные члены, затем xᵢ = Δᵢ/Δ.

Что ловить при проверке: неверно переписанную строку/столбец и знак в определителе. Именно арифметика детерминанта чаще ломает уже правильно выбранный метод.
