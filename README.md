# MIPT Physics Labs

Интерактивные учебные помощники к лабораторным работам по физике.

## Структура

- `index.html` — главная страница проекта.
- `lab-1.1.4/` — статистика космического фона.

Каждая следующая лабораторная добавляется в отдельную папку `lab-X.X.X/`.

## GitHub Pages

Публикуется из ветки `main`, папка `/ (root)`.
