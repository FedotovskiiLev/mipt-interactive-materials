# Интерактивные материалы МФТИ

Независимый открытый учебный проект с интерактивными материалами по
университетской математике, физике и лабораторному практикуму.

> **Понять, увидев в действии.**

Идея проекта — не заменять учебник калькулятором, а связывать теорию с
действием: дать определение, показать его на интерактивном примере, предложить
самопроверку и в конце оставить задачу, которую нужно выполнить самостоятельно.

## Что уже есть

### Физика

Доступна лабораторная работа **1.1.4 — «Статистика космического фона»**.

Страница включает:

- теорию с нуля и расширенные пояснения по методичке;
- визуализацию регистрации событий и группировки по времени;
- среднее, дисперсию, стандартное отклонение и ошибку среднего;
- распределение Пуассона и гауссово приближение;
- обработку собственного файла лабораторной программы;
- учебную браузерную версию программы с четырьмя основными графиками;
- самостоятельное построение графиков в Calc, Excel, Word, Python и Google Таблицах;
- тренажёр вопросов.

### Аналитическая геометрия

Доступен материал **первой недели**:

- матрицы и индексы элементов;
- умножение матриц как «строка × столбец»;
- некоммутативность произведения;
- определители 2×2 и 3×3;
- правило Крамера;
- домашняя задача на матрицу, коммутирующую с любой матрицей 2×2;
- самопроверка и аудит вычислений.

Основные учебные источники раздела — А. Е. Умнов,
Д. В. Беклемишев и задачник Беклемишевых и др.

### Библиотека

Личная книжная полка поверх публичной папки Яндекс Диска.

Проект не хранит книги и не содержит заранее заданной ссылки на стороннюю
библиотеку. Публичный адрес подключается пользователем и сохраняется только
локально в браузере.

Каталог используется для поиска, а выбранные книги можно закреплять на
личной полке.

## Принципы учебных материалов

Подробный стандарт находится в [`MATERIAL_STANDARD.md`](MATERIAL_STANDARD.md).

Ключевые правила:

- учебная страница опирается на явно выбранные учебники, задачники или методички;
- обозначения, формулы и нумерация сохраняются в той форме, в которой они
  используются в основном источнике курса;
- расхождения между источниками показываются явно;
- интерактивы должны объяснять идею, а не быть декоративными;
- незнакомые обозначения объясняются до того, как начинают использоваться;
- полное решение домашней задачи не показывается сразу: по умолчанию используется
  лестница подсказок;
- после автоматического инструмента должен оставаться способ выполнить ключевое
  действие самостоятельно.

## Запуск локально

Сборка не требуется. Достаточно отдать корень репозитория обычным статическим
HTTP-сервером, например:

```bash
python -m http.server 8000
```

После этого сайт будет доступен по адресу:

```text
http://localhost:8000/
```

Открывать страницы напрямую через `file://` нежелательно: некоторые функции
браузера и запросы к внешним API работают корректно только через HTTP(S).

## Развёртывание

Проект рассчитан на GitHub Pages и не требует серверной части, базы данных или
секретных ключей.

Основной код — обычные HTML, CSS и JavaScript. Данные, которые должны оставаться
локальными для пользователя, сохраняются средствами браузера.
