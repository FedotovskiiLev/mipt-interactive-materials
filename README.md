# Интерактивные материалы МФТИ

Набор небольших интерактивных учебных материалов по университетской математике, физике и лабораторным работам.

Рекомендуемое имя репозитория: `mipt-interactive-materials`. Проект вырос из одной страницы физической лабораторной в общий набор интерактивных учебных материалов.

## Разделы

### Физика

Интерактивные материалы по курсу физики и лабораторному практикуму.

Сейчас доступна лабораторная **1.1.4 — «Статистика космического фона»**. На странице есть обработка экспериментальных данных, группировка по времени, расчёт статистических величин, сравнение с распределением Пуассона и приближением Гаусса, графики и учебный симулятор.

### Библиотека

Визуальная книжная полка для публичных библиотек на Яндекс Диске.

Сам проект **не хранит книги и не содержит заранее заданной ссылки на чужой диск**. Пользователь самостоятельно вставляет публичную ссылку на папку. Она сохраняется только в его браузере через `localStorage` и не отправляется в репозиторий.

Библиотека умеет находить PDF, DJVU и EPUB, распределять распознанные книги по предметам, дополнять известные издания статическими метаданными, показывать книги на полках или списком, искать по каталогу и открывать выбранный файл через публичный просмотр Яндекс Диска.

## Принципы проекта

- Полностью статический сайт: HTML, CSS и обычный JavaScript.
- Никакого собственного сервера, базы данных, секретных ключей и обязательной сборки.
- Интерактивные материалы должны объяснять идею и помогать разобраться, а не автоматически выдавать готовую учебную работу.
- Разделы по разным предметам остаются самостоятельными, но используют общую навигацию и оформление.
- Большие внешние материалы, например книги, не добавляются в Git-репозиторий: сайт работает со ссылками или публичными источниками, которые подключает сам пользователь.

## В планах

Постепенное добавление интерактивных материалов по математическому анализу, линейной алгебре, аналитической геометрии, общей физике и другим лабораторным работам.

## Версии

- **0.6** — библиотека получила навигацию по реальной структуре папок, улучшенный поиск и экспериментальный прямой просмотр PDF внутри сайта.


### 0.7

Библиотека разделена на личную полку и каталог. Каталог работает только внутри выбранного крупного раздела источника и сохраняет реальную структуру папок Яндекс Диска. Книги можно закреплять на личной полке. Для PDF добавлен собственный просмотрщик на PDF.js: сайт пытается получить байты PDF и отрисовать страницы сам, чтобы не зависеть от заголовка `Content-Disposition: attachment`.


### 0.8

Интерфейс библиотеки упрощён вокруг идеи личной полки. Каталог вынесен в отдельное окно и нужен только для добавления книг. Выбранный крупный раздел источника (например, «1 курс») остаётся единственным рабочим каталогом, остальные курсы не занимают интерфейс.

Удаление книги с полки теперь возможно только в отдельном режиме «Управление» и требует подтверждения.

Предыдущая попытка встроенного PDF.js-просмотра удалена: временные ссылки Яндекс Диска выдаются с CORS-ограничением и не читаются JavaScript со статического GitHub Pages. Вместо этого 0.8 передаёт временную ссылку сервису Яндекс Просмотр документов (`docviewer.yandex.ru`) и пытается встроить уже его. Это не требует чтения байтов PDF нашим JavaScript.


### 0.9

Встроенное окно просмотра удалено. `docs.yandex.ru` запрещает отображать себя внутри iframe чужого сайта, поэтому такой просмотрщик не может работать на GitHub Pages независимо от CSS или JavaScript.

Теперь нажатие на книгу сразу открывает Яндекс Просмотр документов в новой вкладке, минуя промежуточную публичную страницу файла. Сайт создаёт вкладку в момент клика, получает через API временную ссылку на документ и перенаправляет уже открытую вкладку в `docviewer.yandex.ru`. Если API не вернул ссылку, используется обычная публичная страница файла как резервный вариант.


### 0.10

Лабораторная 1.1.4 полностью переработана по принципу «Понять, увидев в действии». Теория и интерактивы основаны только на предоставленной методичке этой работы. Добавлены: наглядная схема регистрации и группировки, пошаговый расчёт среднего/дисперсии/σ/ошибки среднего, интерактивная гистограмма частот, теоретический закон Пуассона с изменяемым средним, визуализация относительной ошибки через `nΣ`, точный маршрут заданий из методички, расширенный анализ собственных данных и мини-журнал наблюдений для симуляций лабораторной программы. Самодельные генераторы экспоненциального распределения и Парето удалены, поскольку методичка не задаёт их программную параметризацию.


### 0.11 — лабораторная 1.1.4

Страница 1.1.4 расширена как кандидат на эталонный учебный материал проекта.

- добавлен сворачиваемый раздел «Теория с нуля» по всем понятиям, которые используются в предоставленной методичке;
- добавлен словарь обозначений;
- теория не дополняется чужими формулами: если методичка не задаёт конкретную параметризацию, сайт это прямо отмечает;
- добавлена учебная веб-версия лабораторной программы: воспроизведение серии, текущие статистики, гистограмма и симуляция закона Пуассона;
- экспоненциальное распределение и Парето не получают самодельного генератора, потому что предоставленная методичка не задаёт его формулу;
- самопроверка заменена на тренажёр с расширенным банком вопросов и режимами «10 случайных» / «все вопросы».


### 0.12 — финал-кандидат 1.1.4

Учебная программа перестроена по реальным файлам лабораторной программы и воспоминанию о её четырёх графиках. Эксперимент и симуляция теперь являются отдельными источниками одной и той же числовой серии. Добавлены четыре синхронных окна: отсчёты во времени, гистограмма, среднее при росте N и ошибка среднего.

Парсер читает служебные строки файлов: тип режима, начало/остановку эксперимента, распределение, `mu` и заявленное число точек. В релиз включены обезличенные реальные примеры 2022/2026. Poisson можно генерировать по формуле из методички; режим `exp` представлен реальной архивной серией, поскольку точный алгоритм генератора в предоставленных материалах не задан.
- в учебной программе исправлено управление воспроизведением: «Пауза» сохраняет текущую позицию, после неё кнопка становится «Продолжить»; только «Сброс» или повторный запуск после завершения возвращают серию к началу.
