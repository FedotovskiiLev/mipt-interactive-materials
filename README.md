# Интерактивные учебные материалы

Материалы для разных предметов и курсов: объяснения, редактируемые примеры и самостоятельные задачи. Сейчас доступны матрицы и лабораторная по физике; проект открыт для химии, программирования и других направлений. Независимый проект, не официальный ресурс МФТИ.

## Материалы

- [Матрицы и определители](analytic-geometry/week-1/) — умножение, определители 2×2 и 3×3, правило Крамера, задачи и самопроверка.
- [Статистика космического фона](physics/labs/1.1.4/) — лабораторная 1.1.4: распределения, погрешности, группировка и обработка своих данных.
- [Книжная полка](bookshelf/) — каталог публичной папки Яндекс Диска и сохранённый в браузере список книг. Книг и заранее заданной ссылки на библиотеку в репозитории нет.

## Локальный запуск

Нужен Node.js. Сборки и установки пакетов для самого сайта нет.

```sh
node scripts/serve.cjs
```

Откройте http://127.0.0.1:4173/mipt-interactive-materials/. Сервер также обслуживает сайт от корня. Порт можно изменить переменной PORT. Сервер предназначен для локального просмотра.

## Проверка

Для браузерной проверки нужны Chrome и пакет Playwright (npm install --no-save playwright). Запустите локальный сервер, затем в другом терминале:

```sh
node scripts/check.cjs
```

Проверяются восемь страниц на широком и узком экране, якоря, поиск и фильтры, вычисления определителей и Крамера, обработка лабораторных данных, старый адрес лабораторной и каталог без JavaScript. Снимки сохраняются в test-results/ и не попадают в Git. BASE_URL позволяет проверить другой адрес.

## Устройство проекта

Обычные HTML, CSS и JavaScript. Общая основа — assets/site.css, визуальное оформление — assets/editorial.css. Интерактивы хранятся рядом со страницами. Поиск главной — assets/catalog.js. Сторонние шрифты и библиотеки для отображения страниц не нужны.

Сайт рассчитан на GitHub Pages: публикуется корень выбранной ветки. Относительные ссылки работают под /mipt-interactive-materials/. Настройки Pages меняются в репозитории; отдельной сборки нет. Старый адрес lab-1.1.4/ перенаправляет в physics/labs/1.1.4/.
