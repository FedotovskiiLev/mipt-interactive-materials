# Contributor License Agreement

Это упрощённый шаблон соглашения для вкладов в проект.

**Важно:** CLA стоит пересмотреть в будущем, это временный вариант

## 1. Права на вклад

Участник сохраняет авторские права на свой вклад.

## 2. Лицензия владельцу проекта

Передавая вклад для включения в проект, участник предоставляет владельцу
проекта постоянную, всемирную, неисключительную, безвозмездную и, насколько
это допускается применимым правом, безотзывную лицензию на использование,
копирование, изменение, создание производных работ, публичный показ,
распространение и сублицензирование этого вклада.

Эта лицензия также позволяет владельцу проекта включать вклад в версии,
предлагаемые на иных, в том числе коммерческих или проприетарных, условиях.

## 3. Публичные лицензии проекта

Если для конкретного материала не указано иное:

- код публикуется по `AGPL-3.0-or-later`;
- оригинальный непрограммный учебный контент — по `CC-BY-SA-4.0`.

Дополнительная лицензия владельцу проекта не отнимает у автора право
самостоятельно использовать собственный вклад.

## 4. Подтверждения участника

Участник подтверждает, что:

- вправе предоставить вклад;
- не знает о нарушении чужих авторских или иных прав своим вкладом;
- обозначил включённые сторонние материалы и условия их использования;
- если для заключения такого соглашения по возрасту или иным причинам
  требуется согласие законного представителя или другой стороны, такое
  согласие получено до принятия вклада.

## 5. Принятие

Проект не обязан принимать или сохранять любой предложенный вклад.

Согласие можно фиксировать в pull request фразой:

> Я согласен с Contributor License Agreement из `CLA.md`.

В будущем проект может заменить этот способ на отдельный процесс подписания.
